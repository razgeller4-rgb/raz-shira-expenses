# הפעולה הבאה

רז אישר את הכיוון החזותי וביקש לשמר כל יכולת ונתון. [חוזי השימור מ־14.09](../design/specification/contracts-2026-09-14/README.md) הם ההמשך הפעיל למטריצת 57 היכולות.

בוצע: שיוך 151 פקדים פתוחים; יעדים לכל 506 מופעי תגיות; 17 קבוצות טפסים ו־71 שדות לוגיים; 35 שדות כלי שכר; 39 הגדרות מדדים/עמודות; מידע רקע, מצבי עבודה ותרחישי קבלה. אין עדיין כיסוי חזותי או runtime מלא.

המשך: להמיר את חוזה המסכים והזרימות למפרט חזותי מדוד, להשלים פלטים דינמיים וכללי null/אפס לכל מדד, ולבדוק גרסה חיה וזרימות מחוברות. אסור לחזור לשאלה איזה כיוון בסיסי לבחור, או להשמיט מסלולים שלא הופיעו בארבע התמונות.

## בקשת מחקר נוספת — רשימת סופר (14.09)

לקרוא [מחקר הקניות](../research/2026-09-14/grocery/GROCERY_RESEARCH_HE.md) ולשלב את GROC-01–06 מהבקלוג. מדובר בהרחבה חדשה, לא ביכולת קיימת שנסקרה במטריצת השימור. השלב הבא המוצע: רשימת הפתקים והסניפים → מפרט רשימה ומצב קנייה; לא להוסיף ספק OCR/שליחת קבלות/התראות אמיתיות כחלק סמוי מהמחקר. הבקשה אינה מבטלת את התכנון ושימור היכולות הקיימים.

### עדכון GROC — הרשימה התקבלה

לקרוא את [הניתוח האישי](../data/private-grocery/PERSONAL_LIST_REVIEW.md) ואת catalog.json שלצדו: 134 שורות מקור, 132 שמות שונים, שלושה תיקוני שם מאושרים ושתי קבוצות כפילות טקסטואלית שלא מוזגו. הרשימה היא קטלוג קבוע ולא רשימת חוסרים פעילה. קבצי המקור והקטלוג פרטיים ומוחרגים מ־git; אין להעתיקם לנכסי אתר או לדמו פומבי. ההמשך: קטלוג → בחירה לקנייה נוכחית, בירור סניפים וזיהוי מוצרים הדרגתי; להמשיך באותו כיוון עיצוב.
