# הפעולה הבאה

רז אישר את הכיוון החזותי וביקש לשמר כל יכולת ונתון. [חוזי השימור מ־14.09](../design/specification/contracts-2026-09-14/README.md) הם ההמשך הפעיל למטריצת 57 היכולות.

בוצע: שיוך 151 פקדים פתוחים; יעדים לכל 506 מופעי תגיות; 17 קבוצות טפסים ו־71 שדות לוגיים; 35 שדות כלי שכר; 39 הגדרות מדדים/עמודות; מידע רקע, מצבי עבודה ותרחישי קבלה. אין עדיין כיסוי חזותי או runtime מלא.

המשך: להמיר את חוזה המסכים והזרימות למפרט חזותי מדוד, להשלים פלטים דינמיים וכללי null/אפס לכל מדד, ולבדוק גרסה חיה וזרימות מחוברות. אסור לחזור לשאלה איזה כיוון בסיסי לבחור, או להשמיט מסלולים שלא הופיעו בארבע התמונות.
