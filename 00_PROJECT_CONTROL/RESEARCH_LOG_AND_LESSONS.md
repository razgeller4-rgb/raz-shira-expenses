### F-14 · 🔴 פריט "טופל" בדשבורד חוזר אחרי רענון — נמצא ותוקן בדמו

**איך נמצא:** רז בדק את רשימת הבדיקה בפועל באייפון. כל הסעיפים עברו **חוץ** מ"לסמן פריט כטופל → לרענן → הוא לא חוזר" (סעיף 3 ב-`DEMO_CHECK_LIST.md`).

**הסיבה:** `dismissReviewItem()` (שורה 6091) כתב ל-`localStorage` אבל **לא קרא ל-`markLocalDataChanged()` ולא ל-`scheduleCloudSync()`** — בניגוד לכל פונקציית שמירה אחרת באפליקציה (`saveOverrides`, `saveDebtData` וכו', כולן עושות את שני אלה). התוצאה: הדחיפה לענן אף פעם לא קרתה, ובברענון `pullCloudSnapshot()` הביא מהענן רשימת "טופלים" ישנה ודרס את המקומית.

זה בדיוק סוג הבאג ש-`18f64dc` התכוון לסגור (רישום המפתח ברשימת הסנכרון) — אבל נתיב הכתיבה הספציפי הזה לא חובר לזה.

**התיקון (בדמו בלבד, עדיין):**
```js
function dismissReviewItem(id){
  const dismissed = getDismissedReviewItemIds();
  if(!dismissed.includes(id)) dismissed.push(id);
  localStorage.setItem(getDismissedReviewItemsStorageKey(), JSON.stringify(dismissed.slice(-100)));
  markLocalDataChanged();
  scheduleCloudSync();
  render();
}
```

**אימות שהתיקון בקוד:**
```bash

# צפוי: 2
```

**אימות פונקציונלי שנדרש מרז (לא הוחלף בקוד):** לחזור בדיוק על סעיף 3 בצ'קליסט — לסמן טופל, לרענן מהאייפון, לוודא שהוא לא חוזר.

**סטטוס:** 🟡 תוקן בדמו, **ממתין לאישור רטסט** מהאייפון · **ראיה:** גרפ למעלה ירוץ אחרי commit
